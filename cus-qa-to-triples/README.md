# CUS-QA to Triples

A pipeline for converting the [CUS-QA dataset](https://huggingface.co/datasets/ufal/cus-qa) - a collection of Czech and Slovak questions and answers - into structured triples, including both factual and counter-factual variants.

Dataset | Number of entries
-|-:
cus-qa-dev-czech-text (original) | 530
factual triples | 530
counter-factual-triples (`misto,jmeno_clovek,datum,cislo`) | 460

## Overview

Each CUS-QA record (a question, answer, and category) is transformed into an RDF-style triple of the form `Subject | Predicate | Object`.

**Input:**

| Question | Answer | Category |
|---|---|---|
| Pro jaké divadlo skládal Karel Plíhal? | Pro Moravské divadlo Olomouc. | culture |

**Output:**

```xml
<entry category="culture" eid="Id0" shape="NA" shape_type="NA" size="1">
    <originaltripleset>
        <otriple>Karel_Plíhal | composedFor | Moravské_divadlo_Olomouc</otriple>
    </originaltripleset>
</entry>
```

## Pipeline

### 1. Creating Triples

A question-answer pair is passed to an LLM (in **English**), which synthesizes them into a single phrase and extracts the corresponding triple.

### 2. Tagging Subjects and Objects

In a separate prompt without any context from the previous one (in **Czech**), the LLM assigns semantic type tags to each subject and object. Tags are defined in `MemberType` inside [`constants.py`](./constants.py):

| Tag Czech | Tag Slovak | English |
|---|---|---|
| `jmeno_umelecke_dilo` | `meno_umelecke_dielo` | Name of an artwork |
| `jmeno_clovek` | `meno_clovek` | Person's name |
| `jmeno` | `meno` | Generic name |
| `misto` | `miesto` | Place |
| `datum` | `datum` | Date |
| `cislo` | `cislo` | Number |
| `zamestnani` | `zamestnanie` | Occupation |

These tags drive counter-factual generation. They can be freely extended - updating the enum automatically updates the prompt, though tagging must be re-run afterwards.

### 3. Creating Counter-factual Triples

Counter-factual data is generated by swapping tagged entities across entries. You can configure which `MemberType` tags could be changed and how many substitutions occur per record (between 1 and `max-changes`).

For each record, the pipeline collects all tagged subjects and objects, finds other entities of the same type elsewhere in the dataset, and randomly substitutes one or more of them - producing a semantically plausible but factually incorrect triple.

**Example:**

*Original entry:*

| Subject | Predicate | Object |
|---|---|---|
| J._H._Krchovský `[jmeno_clovek]` | authorOf | Na_samém_konci `[jmeno_umelecke_dilo]` |
| Na_samém_konci `[jmeno_umelecke_dilo]` | type | báseň `[None]` |
| Na_samém_konci `[jmeno_umelecke_dilo]` | writtenOn | fasáda_domu `[None]` |
| fasáda_domu `[None]` | location | nizozemské_město_Leiden `[misto]` |

If `Na_samém_konci [jmeno_umelecke_dilo]` is selected for substitution and replaced with `Starci_na_chmelu` (drawn from another entry), every occurrence is updated consistently:

*Counter-factual result:*

| Subject | Predicate | Object |
|---|---|---|
| J._H._Krchovský `[jmeno_clovek]` | authorOf | Starci_na_chmelu `[jmeno_umelecke_dilo]` |
| Starci_na_chmelu `[jmeno_umelecke_dilo]` | type | báseň `[None]` |
| Starci_na_chmelu `[jmeno_umelecke_dilo]` | writtenOn | fasáda_domu `[None]` |
| fasáda_domu `[None]` | location | nizozemské_město_Leiden `[misto]` |

## Usage

**Step 1 - Generate phrases, triples, and tags:**
```bash
python cus-qa-to-triples/prompt-llm.py cz
python cus-qa-to-triples/prompt-llm.py sk
```

**Step 2 - Create counter-factual data:**
```bash
python cus-qa-to-triples/create_CF_data.py cz --max-changes 1 --tags misto,jmeno_clovek,datum,cislo
python cus-qa-to-triples/create_CF_data.py sk --max-changes 1 --tags miesto,meno_clovek,datum,cislo
```

**Step 3 - Export to triples format:**
```bash
python cus-qa-to-triples/setup_triples.py
```

## Data Files

All working files are stored in `cus-qa-to-triples/data/`:

| File | Description |
|---|---|
| `cus-qa-text-cz.parquet` | Raw questions and answers from CUS-QA (downloaded on first use) |
| `Factual-phrased.xml` | Factual triples with tags and LLM-generated phrases |
| `Factual-triples.xml` | Factual triples (clean) |
| `CounterFactual-phrased.xml` | Counter-factual triples with tags, derived from `Factual-phrased.xml` |
| `CounterFactual-triples.xml` | Counter-factual triples (clean) |
