1. Write a single, fluent {language} phrase that naturally incorporates all information from the question–answer pair.

Output format:

```xml
<phrase>The fluent {language} phrase combining all facts.</phrase>
<mtriple>Subject | predicate | Object </mtriple>
<mtriple>Subject | predicate | Object </mtriple>
<mtriple>Subject | predicate | Object </mtriple>
...
```

Rules:

- Predicates must be in English, concise, and in camelCase (e.g., `foundingDate`, `numberOfEmployees`).
- Subjects and objects have to be in the original language ({language}).
- Normalize values in triplets: dates -> `YYYY-MM-DD`, multi-word names -> `Snake_Case_With_Underscores`, numbers -> digits only (e.g., `29000` not `29,000`).
- The original {language} phrase should be reconstructable from the triplets alone.
- Output ONLY the result, nothing else.
